# SDK Examples

These examples show the intended usage shape for the TypeScript SDK.

- `auth-flow.ts`: OAuth authorize URL, PKCE, token exchange, and revocation.
- `browser-spa-auth.ts`: browser SPA auth flow with PKCE and callback token exchange.
- `server-express-auth.ts`: server-side Express usage with session-cookie auth.
- `admin-apps-users.ts`: app and user administration.
- `admin-roles-groups.ts`: role and group administration with assignment flows.
- `escalation-approval-break-glass.ts`: user escalation request, admin approval, activation, and break-glass flow.
- `enterprise-scim-onboarding.ts`: SCIM token, mapping, and reconcile onboarding flow.
- `enterprise-saml-onboarding.ts`: SAML service provider onboarding with metadata and assertions.
- `fullstack-rbac/`: frontend login + backend OAuth validation + role/permission protected backend routes.

The example files are not part of the SDK build. They are lightweight usage references for implementation and documentation work.
